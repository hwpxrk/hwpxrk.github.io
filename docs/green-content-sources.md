후보자 소개에 원본 증명사진 3장을 추가했습니다. 원본은 `1_선거운동본부 등록 서류` 폴더의 이름이 명시된 `7_1`, `7_2`, `7_3` 후보자 증명사진 JPEG입니다. 정책자료집 RevH의 이름 옆 사진과 대조했으며, 원본 사진·PPTX 내 이미지·웹 자산의 바이트가 일치합니다.

원본을 그대로 사용하여 송선빈 사진은 약 1.9MB입니다. 화면 진입 시 불러오는 `loading="lazy"`를 적용했으며, 추후 이미지 용량을 줄일 때에는 원본을 보관하고 별도의 웹용 파일을 만드는 방식이 적합합니다.

기본 경로와 `/council` 빌드, 사진 3개의 HTTP 응답 및 파일 일치, 기존 연혁·검색 데이터·앵커 보존, CSS 파싱과 변경 파일 공백 검사를 통과했습니다. Safari 데스크톱과 390px·320px iframe에서 사진·이름·연혁 배치를 확인했습니다. 실제 모바일 기기 검증은 수행하지 않았습니다.

## 원본 간 차이와 후속 편집 사항

- **장학 수혜 학기:** 박현욱 후보의 2024년 최우수성적장학은 소개 PPTX 4번에서 2학기, RevH 4쪽에서 1학기로 다릅니다. 2026년은 소개 PPTX에서 1·2학기, RevH에서는 1학기입니다. 초안에는 공통으로 확인되는 2024·2025·2026년만 표기했습니다. 학기를 표시하려면 원본을 먼저 정리해야 합니다.
- **출마의 변 날짜:** 별도 출마의 변은 2026-11-12, RevH 7쪽은 2026-11-14, 이전 소개 PPTX 6번은 2026-11-23입니다. 웹의 출마의 변은 해당 문서 전용 파일의 날짜인 11월 12일을 유지했습니다.
- **필진:** 선거운동본부 구성원이라는 사실만으로 집필자나 편집 담당자로 배정하지 않았습니다. 개인별 이름·소개 문장·담당 글이 정리되면 현재의 방향 소개 아래에 추가할 수 있습니다.
- **확정되지 않은 지원 규모:** 동아리 지원금 인상액은 RevH 작성 시점에 미확정입니다. 키트는 사전 수요조사와 구매 방식, 공간 예약제는 검토, 교육과정 및 소프트웨어 계약은 학교에 건의·요청하는 과제로 표현했습니다.
- **초안의 범위:** 사업을 이미 시행했다는 성과 표현, 임의의 행사 날짜·연락처·신청 링크는 추가하지 않았습니다. 글에 서술된 사업은 공약입니다.
